テイルズRPGの2周目を形作るシステムの中で、グレードショップほど大きな影響を持つものはない。そしてテイルズ オブ エターニア リマスターのグレードショップは、発売日を前にして復帰ファンなら誰もが理解しておきたい唯一の仕組みだ。グレードは周回ではなく戦闘成績によって稼ぐため、上手く戦うプレイヤーに報いる——そして装備、レベル、所持金を新たな周回へ引き継ぐ伝統的な方法でもある。本ガイドでは、グレードの稼ぎ方、ショップで一般的に提供されるもの、そして購入計画の立て方を分解し、両世界を巡る2周目を強い状態で始められるようにする。

## テイルズ オブ エターニア リマスターにおけるグレードショップとは

グレードはテイルズ オブ エターニアにおける第三の通貨であり、ガルドや経験値と並ぶ存在だ——そしてどちらとも全く異なる挙動をする。宝箱から拾うことも、装備を売って得ることも、商人に受け取ってもらうこともできない。グレードは戦闘後に、*どのように*戦ったかによって与えられる。どれだけ速く終えたか、どれだけ綺麗にダメージを避けたか、どれだけ長くコンボチェーンを繋げたか、といった基準だ。

2001年のオリジナル版では、その蓄積されたプールを後の周回で永続的な有利と交換できた。その交換所がグレードショップであり、単なるストーリー1周を復帰プレイヤーにとっての長期プロジェクトに変えるものだ。

表を見る前に、正直な注意点を一つ。バンダイナムコの[公式テイルズ オブ エターニア リマスター ページ](https://www.bandainamcoent.com/games/tales-of-eternia-remastered)では、強化されたビジュアル、QoL改善、アグレッシブ リニアモーションバトルシステムが紹介されているが、グレードショップの価格表は公開されていない。以下のカテゴリは、オリジナル版でこのシステムがどう機能していたか、そしてテイルズシリーズがそれ以降グレードをどう扱ってきたかを反映している。計画の枠組みとして扱い、実際にショップの前に立ったら正確なコストを確認してほしい。

| 通貨 | 入手元 | 購入できるもの | 新しい周回へ持ち越せるか？ |
|---|---|---|---|
| ガルド | 敵、宝箱、装備の売却 | 武器、防具、宿屋、アイテム | グレードショップで購入した場合のみ |
| 経験値 | すべての戦闘 | レベル、ステータス、新しい術技 | グレードショップで購入した場合のみ |
| グレード | 戦闘成績 | 次の周回のための特典と修正要素 | はい——それが本来の目的 |

実用的な結論：ガルドと経験値は使って消えるものだ。グレードは投資であり、セーブデータより長く生き残るよう明確に設計された、ゲーム内唯一のリソースである。

## グレードの稼ぎ方：戦闘回数ではなく戦闘成績

新規プレイヤーが最もよくやる間違いは、グレード稼ぎのために作業的に戦うことだ。弱い敵500体とゆっくり雑に戦うより、本当に危険な相手と効率的に20戦する方が、得られるグレードは少なくなることがある。ゲームが測っているのは忍耐力ではなく技術だ。

テイルズ オブ エターニア リマスターは、通常攻撃を術技へ繋げることを軸にした2Dリアルタイムシステム、アグレッシブ リニアモーションバトルシステムで動く。この設計はグレードにとって偶然ではない——長く途切れないコンボは、ゲームが報酬を与えるために使う最も明確なシグナルの一つだ。

| 戦闘要素 | グレードへの影響 | 実践のコツ |
|---|---|---|
| クリアタイムが速い | 増加 | 最強の術技で開幕し、停滞しない |
| パーティメンバーが戦闘不能にならない | 増加 | 反応ではなく先回りしてガードと回復を行う |
| 長いコンボチェーン | 増加 | 通常攻撃から術技へ、途切れさせずに繋げる |
| 高レベルの敵を倒す | 増加 | フィールドの雑魚ではなく、やり込み要素と戦う |
| 戦闘から逃げる | 減少 | 乱戦でも戦いを終わらせる |
| パーティ全滅の繰り返し | 減少 | 難易度を下げるか、意図的に撤退する |
| 毎戦アイテムに頼る | 減少することがある | 料理、術技での回復、リソース管理を行う |

難易度も重要だ。テイルズシリーズ全体で、難易度設定は獲得グレードの倍率として機能し、過去のリマスターでのプレイヤー経験からも同じパターンが当てはまると考えられる。クレジットが流れる前に大量のグレードを貯めたいなら、終盤を高難易度でプレイしよう。ただしトレードオフは現実だ。高難易度での全滅は、その戦闘で得られるはずだったグレード以上に失う。

妥当な目標は、ゲーム前半で戦闘のリズムを学び、後半で意識的にグレードを貯めることだ。両方を同時に最適化しようとすると、たいていどちらも上手くいかない。

## グレードショップで一般的に購入できるもの

グレードは有限なので、何を買うかの決定は、稼ぐ決定以上に重要だ。正確な品揃えはタイトルによって異なるが、カテゴリはシリーズを通して驚くほど一貫している。

| 特典カテゴリ | 効果 | 一般的な優先度 |
|---|---|---|
| アイテムと装備の引き継ぎ | 次の周回へ持ち物を維持する | 高 |
| レベルまたは経験値の引き継ぎ／ブースト | 序盤の作業を完全にスキップする | 高 |
| 術技とスキルの引き継ぎ | 戦闘キットを完全に保持する | 高 |
| ガルドの引き継ぎ | 所持金をそのまま維持する | 中 |
| グレード獲得倍率 | 今後のグレード稼ぎを速くする | 中 |
| 難易度と戦闘の修正要素 | 挑戦、混沌、あるいはその両方を追加する | 中 |
| コスチューム、称号、外見要素 | 自慢材料とフォトモードの燃料 | 低。ただしコンプリート志向なら別 |

根本的な論理は単純だ。繰り返し作業をなくすものは、見た目が良くなるだけのものより価値が高い。引き継ぎ特典は複利的でもある。装備の良いパーティは2周目で戦闘をより速く綺麗に片付け、それがより多くのグレードを生み、さらに強い3周目を支える。

グレードが一度の購入分しかないなら、最も多くの時間を節約する引き継ぎオプションを選ぼう。ほとんどのプレイヤーにとってそれはガルドではなく装備とレベルだ——金は再び稼ぎやすいが、フル装備を組み直すのはそうではない。

## 計画する価値のある4つのグレードショップ構成

2周目に求めるものはプレイヤーによって異なり、テイルズ オブ エターニア リマスターのグレードショップはそのすべてを支えられる柔軟さを持つ。使う前に方針を決めよう。グレードは返金されない。

| プレイスタイル | 最初に買うもの | スキップを検討するもの | 機能する理由 |
|---|---|---|---|
| ストーリー再体験 | 経験値／レベルの引き継ぎ、アイテム引き継ぎ | 外見要素、過酷な修正要素 | 終盤のストーリー展開に速く到達できる |
| コンプリート志向 | アイテム引き継ぎ、外見要素、グレード倍率 | 理想的にはなし | すべての収集要素に手が届く |
| 戦闘重視 | 術技引き継ぎ、高難易度、敵の修正要素 | ガルド引き継ぎ | 金より技術に報いる |
| カジュアル2周目 | ガルド引き継ぎ、アイテム引き継ぎ、経験値ブースト | 過酷なものすべて | リラックスした低ストレスな再プレイ |

各アプローチについての補足：

- **ストーリー再体験**は速度が重要だ。すでに筋は知っている。見逃したシーンを見て、スキップしたコンテンツに到達したい。レベルと装備の引き継ぎが最速でそこへ連れて行く。
- **コンプリート志向**の周回はアイテム引き継ぎの恩恵が最も大きい。サイドコンテンツは特定の装備や消耗品を要求することが多く、再び集めるのは苦痛だからだ。
- **戦闘重視**の周回では難易度修正要素が輝く。過去のテイルズ リマスターに関するコミュニティ報告では、高難易度設定が最も満足のいく再プレイ方法だと一貫して語られている。敵の行動とボスの圧力が明らかに変わるからだ。
- **カジュアル2周目**のプレイヤーは、すべてを買いたい衝動に抵抗すべきだ。短いQoL特典リストが、ゲームを第二の仕事にせず楽しく保つ。

過去のテイルズ リマスターでのプレイヤー経験から、ほとんどの人は最初のNew Game+で引き継ぎ特典を買い、修正要素はより自信がついた後の周回に取っておくようだ。その順序は否定しがたい。

## ラスボスを倒す前の準備チェックリスト

グレード計画はエンディング後ではなく、ラスボス前の活動だ。引き返せない地点を越えると、選択肢は狭まる。

| 手順 | 重要な理由 |
|---|---|
| 終盤を高難易度でプレイする | 難易度は通常、獲得グレードに倍率をかける |
| やり込みダンジョンと強敵をクリアする | 強い敵ほど1戦あたりのグレードが多い |
| 最良の装備は売らずに装備しておく | アイテム引き継ぎは所持しているものを保持する |
| 最終ダンジョン前にサブクエストと称号を終える | 後から回収できない報酬がある |
| 最後の戦いの前にグレード合計を確認する | 実際の数字に基づいて購入計画を立てられる |
| 2周目の目標を事前に決める | 引き継ぎ構成と挑戦構成は両立しない |

小さな習慣も二つ役立つ。第一に、ラスボス前に別スロットでセーブし、希望額に届かなかった場合に戻ってグレードを稼げるようにする。第二に、ショップがグレード獲得倍率を提供しているか確認する——もしあれば、再プレイ序盤に買うことで、リスト上のほとんど何よりも早く元が取れる。

またプラットフォーム展開も覚えておこう。リマスターはPlayStation 4とPlayStation 5、Xbox Series X|S、Steam、Nintendo Switchで発売されるため、グレード計画は単一のセーブファイルに固有のものだ。頼れるクロスプラットフォームのグレードプールは存在しない。

## よくある質問

**テイルズ オブ エターニア リマスターにグレードショップはありますか？**
2001年のオリジナル版では戦闘成績からグレードを記録しており、それ以降テイルズシリーズではグレードショップがグレードを使う標準的な場所となっている。バンダイナムコはリマスター用の詳細なショップリストを公開していないため、ストーリークリア後にゲーム内メニューで最終的な品揃えを確認しよう。

**グレードを速く稼ぐには？**
頻繁にではなく効率的に戦おう。速いクリア、戦闘不能ゼロ、長いコンボチェーン、より強い敵はすべてグレード合計を押し上げ、逃走や全滅の繰り返しは下げる。終盤を高難易度でプレイすることが、通常は利用可能な最大の倍率だ。

**テイルズ オブ エターニア リマスターのグレードショップで最初に何を買うべき？**
まず引き継ぎ特典——装備、レベル、術技——から始めよう。これらは最も多くの繰り返し作業をなくす。難易度修正要素と外見要素は、再プレイの感触が分かってから後の周回に取っておこう。

**グレードは周回間で持ち越されますか？**
グレードは永久に持ち越すのではなく、次の周回で使うように設計されている。各新しい旅ごとの一度きりの予算と考えよう。すべてを一度に賄おうとせず、単一の再プレイ目標に合わせて購入を計画しよう。

## 結論

グレードショップは、テイルズ オブ エターニア リマスターを「再プレイする」ことと「*再体験する*」ことの違いを生む。意図を持って戦ってグレードを稼ぎ、終盤の高難易度で貯め、すでに突破できると証明済みの部分を消し去る引き継ぎ特典に使おう。そうすれば、両世界を巡る2周目は1周目より速く、綺麗で、はるかに楽しいものになる。
