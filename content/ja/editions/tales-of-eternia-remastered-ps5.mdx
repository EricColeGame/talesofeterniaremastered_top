| PS4しか持っていない | PS4版 | あなたのハードウェアで動作する唯一のバージョンです |

## リマスター版モード vs オリジナルモード：切り替えの説明

このリリースの最も魅力的な特徴の1つは、表現が固定されていないことです。公式の説明によると、グラフィックと効果音はモード間で切り替えることができ、いつでもオリジナルゲームの懐かしい雰囲気を体験できます。

つまり、1回の購入で同じ冒険を2つの方法で見ることができます：

| 設定 | リマスター版の表現 | オリジナルスタイルの表現 |
| --- | --- | --- |
| ビジュアル | 更新され、クリーンアップされた見た目 | クラシック版に近い |
| 効果音 | 作り直されたオーディオ | オリジナルスタイルの効果音 |
| 利用可能性 | 切り替え可能と説明されている | 切り替え可能と説明されている |
| 最適な用途 | 初めてのプレイヤーと大画面プレイ | ノスタルジーを求めるベテラン |
| 一般的な使用 | デフォルトのプレイ | ノスタルジープレイ、比較動画 |

これは聞こえる以上に大きなことです。単一のビジュアルスタイルを強制するリマスターは、しばしばオーディエンスを二分します。純粋主義者は古い見た目を求め、新参者は新しいものを求めます。切り替え機能は、誰にも妥協を求めることなく、両方に対応します。

私のおすすめは、最初のプレイはリマスター版モードで行い、ストーリーをすんなりと理解することです。その後、2周目ではオリジナルの表現に切り替えましょう。何が起こっているかをすでに知っていれば、戦闘アニメーションにはるかに気づくはずです。

## プレイ方法を変えるQoL機能

ストアページでは、プレイスルーのペースを意味のある形で変える3つの追加要素が強調されています。いずれも見た目だけのものではありません。

| 機能 | 何をするか | 最も恩恵を受ける人 |
| --- | --- | --- |
| 目的地マーカー | 次の目標へと導く | 目的のない徘徊を好まないプレイヤー |
| エンカウント切り替え | 敵とのエンカウントを無効にできる | ストーリー重視のプレイヤーとバックトラッカー |
| 高速オートバトル | オートバトルシーケンスを高速化 | 周回プレイヤーと繰り返しプレイ |

それぞれを最大限に活用する方法は以下の通りです：

1. **最初の10時間は目的地マーカーをオンにしておきましょう。** エターニアの世界は2つの領域にまたがっており、序盤は多くの地名が一度に押し寄せます。
2. **エンカウントをオフにするのは、レベル上げ中ではなく探索中です。** 戦闘を無効にするのは便利さのためであり、戦略ではありません。後の戦いのためにはレベルが必要です。
3. **高速オートバトルは周回プレイに使用しましょう。** それは退屈さを取り除くために存在し、戦闘システムを置き換えるためではありません。
4. **ダンジョンの前にはエンカウント切り替えを再びオンにしましょう。** 手動の戦闘はあなたの技を研ぎ澄まし、パーティの連携を保ちます。

このような機能に対するコミュニティの感情は何年も前から肯定的です。クラシックJRPGで育ったプレイヤーは、リマスターにエンカウント制御と速度オプションを一貫して求めていますが、このリリースはその両方を提供します。

## 戦闘とストーリー：実際に買うもの

ゲームが初めてなら、戦闘が続ける理由です。それはアグレッシブ・リニアモーション・バトルシステム（A-LMBS）で動作し、多様な技の使用、拡張コンボ、各ユニークなパーティメンバー間の連携をサポートします。戦闘は高速でダイナミックな2Dバトルアクションとして展開され、メニュー操作よりも位置取りとタイミングが重要です。

ストーリーの設定も同様に明確です。エターニアは、インフェリアとセレスティアという2つの孤立した領域に分かれた世界です。辺境のインフェリアの村ラシュアンで、リッド・ハーシェルと幼なじみのファラ・エルステッドは、メルディという名の神秘的な少女に出会います。メルディの出自を明らかにしようとするうちに、一行は「大崩落」として知られる衝突が両方の領域を脅かしていることを知ります。

| 用語 | 指すもの |
| --- | --- |
| インフェリア | エターニアの2つの孤立した領域の1つ |
| セレスティア | もう1つの孤立した領域 |
| ラシュアン | 辺境のインフェリアの村で、序盤のストーリーの場所 |
| 大崩落 | 両方の領域を脅かす衝突 |
| グレーター・クレイメル | パーティがその力を利用する元素の精霊 |
| A-LMBS | 戦闘を支えるバトルシステム |

一行の旅は、大災害を防ぐためにグレーター・クレイメル（元素の精霊）の力を利用することを中心に展開します。この構造は戦闘に明確な目的を与えます。確保する新しいクレイメルごとに、チームが戦闘でできることが広がります。

## エディションの選び方：実用的なチェックリスト

購入する前にこれを確認してください：

- **コンソールを確認しましょう。** PS5またはPS4のみです。他のプラットフォーム用のバージョンは記載されていません。

これをPS5で読んでいるほとんどの人にとって、PS5版が明確な答えです。それ以外の人にとっては、PS4版でも同じストーリーをプレイでき、決定は内容ではなく利便性の問題です。
